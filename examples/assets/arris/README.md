Small procedural test assets created for the Resin example (CC0).

`scene.gltf` has a floor, two spheres, and a checkerboard alpha mask. Geometry,
materials, node translations, and the PNG texture are embedded in the glTF.
`studio.hdr` is a 16 × 8 linear Radiance environment with a bright rectangular light.
Use your own static glTF/GLB and equirectangular EXR/HDR for a more detailed scene.
