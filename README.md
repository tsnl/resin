# `resin`

Dependently-typed GPGPU programming with LEAN.

## Setup

```bash
elan toolchain install stable
```

## Use

```bash
lake build
lake exe resin
```

## Reference

- Lean
  - [Style guide](https://leanprover-community.github.io/contribute/style.html):
    100 cols, 2 space body, 4 space continuation, `UpperCamelCase` for types, `lowerCamelCase` for 
    data fields and defs, `snake_case` for proof fields.
